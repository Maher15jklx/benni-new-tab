StartPane заменяет страницу «Новая вкладка» в Microsoft Edge быстрой, спокойной и настраиваемой стартовой страницей. Единственная цель расширения — сделать каждую новую вкладку удобной отправной точкой для поиска, часто используемых сайтов и личных фоновых изображений.

Возможности:
• Поиск в Интернете через поисковую систему по умолчанию, настроенную в Microsoft Edge. StartPane использует только поддерживаемый Edge интерфейс расширений chrome.search и не считывает и не изменяет выбранную систему.
• Не более трёх дополнительных направлений поиска по HTTPS. YouTube и Google Карты заданы изначально, обращение к ним происходит только после выбора и отправки запроса; оба направления можно изменить, удалить или заменить.
• Встроенные быстрые ссылки, личные ярлыки и закреплённые сайты.
• Случайные, ежедневные или фиксированные фоны, а также четыре встроенных фона, доступных без подключения к сети.
• Необязательные онлайн-фоны из Picsum Photos, выбранного пользователем HTTPS API изображений или намеренно импортированного адреса изображения.
• Светлая и тёмная темы, режим концентрации, цветовой акцент и часы в автоматическом, 12- или 24-часовом формате.
• Интерфейс на русском, немецком, английском, испанском, французском, итальянском и польском языках.

Конфиденциальность и прозрачность:
StartPane хранит настройки, ярлыки, закреплённые сайты, дополнительные направления поиска и импортированные изображения только в локальном хранилище расширений Edge. Поисковые запросы не сохраняются. После установки используются локальные фоны, поэтому запрос изображений не отправляется внешнему сервису, пока пользователь осознанно не включит онлайн-источник. При поиске запрос передаётся только выбранному направлению. Если включены онлайн-изображения, только выбранный поставщик получает технически необходимый запрос.

StartPane не содержит аналитики, отслеживания, рекламы или удалённого кода. Разработчик не использует сервер для пользовательских данных, не продаёт и не сдаёт данные в аренду. Весь исполняемый код JavaScript включён в пакет расширения. Локальные данные можно в любое время удалить через настройки.
