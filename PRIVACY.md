# Datenschutz – Benni New Tab

Stand: 18. September 2026

Benni New Tab erhebt, verkauft oder übermittelt keine personenbezogenen Daten an den Betreiber der Erweiterung.

## Lokal gespeicherte Daten

Folgende Daten werden ausschließlich im lokalen Erweiterungsspeicher von Microsoft Edge abgelegt:

- Darstellungs-, Sprach-, Uhr- und Hintergrundeinstellungen
- Eigene Suchanbieter und Shortcuts
- Angepinnte Webseiten
- Importierte Bilder und Icons

Diese Daten verlassen den Browser nicht durch Benni New Tab. Über **Einstellungen > Daten > Zurücksetzen** können sie gelöscht werden. Beim Entfernen der Erweiterung löscht Edge den zugehörigen Erweiterungsspeicher.

## Externe Anfragen

Netzwerkanfragen entstehen nur in diesen Fällen:

- Bei einer aktiven Online-Bildquelle wird ein Bild von Picsum Photos oder der vom Nutzer eingetragenen HTTPS-Bild-API geladen.
- Beim ausdrücklich gestarteten Import einer Bild-URL lädt die Erweiterung die angegebene Datei. Edge fragt dafür eine optionale Berechtigung für die betroffene Domain an.
- Eine Suche oder ein Klick auf einen Shortcut öffnet die vom Nutzer gewählte Webseite. Ab diesem Zeitpunkt gilt die Datenschutzrichtlinie dieser Webseite.

Bei externen Anfragen erhalten die jeweiligen Dienste technisch notwendige Verbindungsdaten wie die IP-Adresse. Benni New Tab betreibt keinen eigenen Analyse-, Tracking- oder Werbedienst.

## Berechtigungen

- `storage` wird zur lokalen Speicherung der oben beschriebenen Daten verwendet.
- Optionale Host-Berechtigungen werden nur auf Nutzeraktion und nur für den Import externer Bilder angefragt.
